# 00 · Start Here

You're a new engineer joining the team that runs EstateFlow. This folder is your entry point —
read both files here, in order, before touching any other folder.

## In this folder

1. [What is EstateFlow?](01-what-is-estateflow.md) — the business problem, the tech stack, a
   tour of the repository.
2. [First day as a DevOps engineer](02-first-day-as-a-devops-engineer.md) — accounts and access
   to request, tools to install, your first real tasks, who to ask when you're stuck.

**Prerequisites:** none — this is where everyone starts.
**Next step after this folder:** [01-architecture](../01-architecture/README.md), then
[02-deployment-guides](../02-deployment-guides/README.md).

## How this whole documentation set is organized

`docs/` is a numbered knowledge base, not a pile of loose files. Each top-level folder is one
theme; files inside are numbered in the order you'd actually use them:

| Folder | Theme | Who uses it most |
|---|---|---|
| `00-start-here/` | Onboarding | New engineers, day 1 |
| `01-architecture/` | How the system fits together | Everyone, once |
| `02-deployment-guides/` | Step-by-step technical how-tos, one per tool | Engineers building/deploying |
| `03-daily-operations/` | Routine health checks | On-call / SRE, every shift |
| `04-runbooks/` | "This specific thing broke — do this" | On-call, during an incident |
| `05-incident-management/` | Severities, roles, templates for incidents | Incident Commander, on-call |
| `06-engineering-records/` | How to document work you did | Everyone, after any task |
| `07-change-management/` | How changes get reviewed and shipped | Everyone opening a PR |
| `08-monitoring-and-observability/` | What's actually instrumented today | Engineers, SRE |
| `09-student-labs/` | Hands-on practice exercises | Students |
| `10-interview-preparation/` | Practice questions tied to this project | Students, pre-interview |
| `11-handover/` | End-of-shift handoff | On-call, end of shift |
| `13-student-assessments/` | Graded assessments, rubric, final capstone exam | Students, instructors |
| `14-incident-simulations/` | 10 gradable incidents, student-facing side (answer keys live in a separate private instructor repo) | Students, instructors |
| `15-star-interview-portfolio/` | 12 full STAR examples + your own editable template | Students, pre-interview |
| `16-student-portfolios/` | A portfolio README template for your own GitHub repo | Students |

See [`docs/README.md`](../README.md) for the full master index and three recommended reading
orders through this material.
