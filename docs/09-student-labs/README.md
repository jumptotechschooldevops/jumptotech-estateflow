# 09 · Student Labs

**Prerequisites:** [02-deployment-guides](../02-deployment-guides/README.md), [04-runbooks](../04-runbooks/README.md)
**Next step:** [13-student-assessments](../13-student-assessments/README.md) for graded
versions of this practice, or [10-interview-preparation](../10-interview-preparation/README.md)
to go straight to interview prep

Hands-on practice, one lab per major technology, ending in a full capstone. Each lab has the
same five parts: **Guided lab** (follow along) → **Independent practice** (do it again without
the hand-holding) → **Controlled failure scenario** (break it on purpose, then fix it) →
**Expected outcome + verification checklist** → **Interview questions + sample answers** tied
to what you just did.

| 03 | [Postgres + EBS lab](03-postgres-ebs-lab.md) | StatefulSet, PVC |
| 04 | [Redis lab](04-redis-lab.md) | Caching |
