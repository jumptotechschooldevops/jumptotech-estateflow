# 15 · STAR Interview Portfolio

**Prerequisites:** [10-interview-preparation](../10-interview-preparation/README.md), [14-incident-simulations](../14-incident-simulations/README.md)
**Next step:** [16-student-portfolios](../16-student-portfolios/README.md)

12 complete STAR (Situation, Task, Action, Result) examples, one per technical area, each
built on real work done in this lab project or a labeled training exercise — never invented
production experience, incident metrics, or business impact.

> **Honesty rule, repeated because it matters:** every example below is clearly a lab/training
> scenario. If you use these in a real interview, say so plainly if asked — "this was a
> training exercise I ran against a lab environment" is a complete, honest, and perfectly
> acceptable answer. See
> [10-interview-preparation/13](../10-interview-preparation/13-discussing-the-project-professionally.md).

## Make these your own

[13 · Editable template](13-editable-template.md) — copy it and replace every example here
with your own verified actions and results once you've actually done the work yourself. A
STAR story in your own words, about something you actually did, is always stronger than a
well-written example about someone else's (even a labeled training) exercise.
