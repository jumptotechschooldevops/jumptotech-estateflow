**Prerequisites:** [README](README.md)
**Next step:** [02 · Portfolio examples and tips](02-portfolio-examples-and-tips.md)

Copy everything in the fenced block below into your own portfolio repository's `README.md`,
then fill it in with your real, verified work as you progress. Delete any section you
haven't done yet rather than leaving it as an unfilled placeholder — an honest, shorter
portfolio is better than one padded with empty sections.

## A note on screenshots and evidence

Store screenshots in a dedicated folder in your portfolio repo (e.g. `evidence/`) and link
to them from the table rows above, rather than only describing what you did in prose — a
reviewer should be able to click through to real proof.
